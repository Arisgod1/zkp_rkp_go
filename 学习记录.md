# Java转go项目练习
## 跑通go服务+/register接口
### 初始化项目
```bash
go mod init github.com/Arisgod1/zkp_rkp_go
```
### 安装依赖
```bash
go get github.com/gin-gonic/gin
go get gorm.io/gorm
go get gorm.io/driver/postgres
go get github.com/spf13/viper
go get go.uber.org/zap
```
### 建目录
在 Windows 上开发 Go 项目，推荐安装 Git for Windows，使用 Git Bash 终端，这样可以直接使用 Linux 风格的命令，避免跨平台兼容性问题。
```git bash
mkdir -p cmd/server pkg/config pkg/logger internal/model internal/repository internal/service internal/controller
```


### 加入真数据库交互

写了个数据库的结构体

然后把PostgreSQL启动

```bash
docker run --name zkp-pg -e POSTGRES_PASSWORD=postgres -e POSTGRES_DB=zkp_auth -p 5432:5432 -d postgres:16
```
